IMPORTANT BEFORE LAUNCH
1. Keep the old GitHub version until the new version is tested.
2. Firebase Authentication -> Email/Password must be Enabled.
3. The first account registered in an empty /users tree becomes the owner.
4. Owner generates one-time activation codes for additional app creators.
5. Apply firebase-rules.json to Realtime Database Rules. Do NOT leave the database at .read=true / .write=true.
6. The public quiz link reads /publicEvents/<eventId>, so competitors do not need an account.
7. Event creators save their private copy under /users/<uid>/events and the shared copy under /publicEvents/<eventId>. Saving the same event ID updates the same shared link.
8. Results are writable by unauthenticated quiz participants so they can submit scores; this is not server-side anti-cheat. Owners can read results for their own events after login.
9. The app is a PWA. Install it from the browser's Add to Home screen / Install app option. The PWA install itself is not password-protected; the app's creator/admin area is protected by Firebase login plus one-time activation codes.
10. The Firebase web configuration in index.html is a client-side Firebase config and is not a secret. Never put a Firebase Admin SDK/service-account private key in this app.

DEPLOY
- Upload/replace these files in the GitHub Pages repository.
- Wait for GitHub Pages deployment to finish.
- Open the live URL and test login, event creation, shared link, edit/save, result submission, and PWA install.
